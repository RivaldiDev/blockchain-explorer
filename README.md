# EthScan Lite - Ethereum Blockchain Explorer

Lightweight Ethereum blockchain explorer showing latest blocks, transactions, and network statistics

## Features

- Latest blocks and transactions with real-time data
- ETH price and gas price tracker
- Network statistics dashboard
- Search by Tx Hash / Address / Block
- Miner info and block rewards
- Dark blue/indigo theme with glassmorphism UI

## Tech Stack

- **Framework:** Next.js 16 (App Router, TypeScript)
- **UI:** shadcn/ui + Tailwind CSS
- **Animations:** Framer Motion
- **API:** Etherscan Free API
- **Deployment:** Vercel

🔗 **Live Demo:** Connect repo to Vercel for auto-deployment
